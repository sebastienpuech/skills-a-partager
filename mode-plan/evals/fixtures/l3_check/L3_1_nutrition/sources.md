# Sources rassemblées par le labo — plafond « hallucination des valeurs nutritionnelles »

- Anthropic — les modèles délèguent les faits vérifiables à des outils / bases de données plutôt que de les générer de mémoire (tool-use pour le grounding factuel).
- Recherche RAG — ancrer une réponse chiffrée sur une base de référence (ex. USDA FoodData Central) réduit l'hallucination des valeurs.
- Prompting — demander au modèle de citer sa source pour chaque valeur améliore la vérifiabilité mais ne garantit pas l'exactitude.
