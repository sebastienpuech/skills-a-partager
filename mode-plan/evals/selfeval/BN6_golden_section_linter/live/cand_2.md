## §10bis. Harnais & signal de succès

Le harnais s'appuie sur un jeu doré de fichiers Python annotés : chaque cas associe un extrait de code à la liste attendue des violations PEP 8 (code de règle + ligne), avec un mélange de cas positifs (entorses réelles) et de cas négatifs (code propre). Le signal de succès se mesure sur ce golden set : **précision ≥ 0,95** et **rappel ≥ 0,90** par famille de règle, chaque violation comparée sur le couple (règle, ligne). Deux garde-fous bloquants : **zéro faux positif sur les cas négatifs** et **zéro crash** (fichier vide, syntaxe invalide, encodage non-UTF-8 renvoient un diagnostic propre). On confronte les sorties à `pycodestyle`/`ruff` comme oracle de référence. Un run est réussi quand l'ensemble du golden set passe ces seuils et que le lot négatif reste vierge.
