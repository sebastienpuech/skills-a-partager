# spec — log-collector (app)
## Vision
Un collecteur qui agrège des fichiers de log en un index cherchable.
## Signal de succès
- Golden set: 5 jeux de logs -> index attendu asséré (diff binaire).
## Fonctions V1
1. Lire les logs. 2. Parser. 3. Indexer. 4. Détection d'anomalies par ML entraîné en ligne. 5. Dashboard temps réel multi-utilisateur avec alerting.
