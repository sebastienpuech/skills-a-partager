## §10bis. Harnais & signal de succès

Golden set de 15-20 paires (texte anglais court → traduction française de référence), couvrant les registres attendus : phrases courantes, idiomes, vocabulaire technique, ton informel/formel, et cas piège (faux amis, unités, noms propres). Chaque sortie est vérifiée sur trois critères automatisables : (1) **langue de sortie** = français (détection via `langdetect`) ; (2) **complétude** = toutes les phrases source rendues, aucun ajout ni omission ; (3) **fidélité sémantique** = similarité d'embedding ≥ 0.85 avec la référence. **Signal de succès** : ≥ 90 % du golden set passe les trois critères, et zéro régression sur les cas piège. Un juge LLM secondaire note la fluidité/naturel sur 5 (seuil ≥ 4/5) pour capter ce que les métriques ratent. Toute traduction sous seuil est journalisée avec son diff.
