## 10bis. Harnais & signal de succès
Golden set : 20 tickets étiquetés à la main (catégorie de référence).
Assertion : catégorie prédite == catégorie de référence (exact match, binaire), accuracy agrégée.
Vérifieur : un script de verification distinct rejoue le golden set à chaque changement et calcule l'accuracy (rejouable, déterministe).
Exemple : ticket "je n'arrive pas à me connecter" -> catégorie "auth".
